# my-voice 产品需求文档

- 文档版本：v0.3（百炼文本润色补充）
- 日期：2026-09-19
- 状态：已确认；实施与验证状态见 [PROGRESS.md](PROGRESS.md)
- 目标平台：macOS 14.4 及以上，优先 Apple Silicon

## 1. 背景与目标

用户需要一个可长期驻留在 macOS 后台的系统级语音输入工具，主要用于中文输入，同时经常混合英文缩写、技术术语、人名、项目名和产品名。普通听写准确率不是唯一目标，专业实体的正确识别、低资源占用和持续适应个人词汇同样重要。

项目目标是：

1. 保留 VoiceInk 已成熟的原生 macOS 能力，包括全局快捷键、录音、焦点恢复、文本写入、App/URL Mode、个人词典和本地模型。
2. 将阿里云百炼 Qwen-Audio-3.0 ASR 作为在线主引擎，以动态热词和短上下文提高中英混输及专业实体识别效果。
3. 网络或云服务不可用时允许切换到本地 ASR，保证基本可用性。
4. 从用户对本次听写结果的后续修改中产生候选纠错，但必须避免把普通改写误学成永久规则。
5. 保持单进程、原生、低打扰的常驻体验，不在实时链路中引入不必要的本地服务、Embedding 模型或本地大模型。

## 2. 已确认的产品决策

| 决策 | 结论 |
|---|---|
| 产品形态 | 原生 macOS 菜单栏应用 |
| 技术底座 | 基于 VoiceInk 源码进行定制，而非从零实现系统输入层 |
| 主识别引擎 | 百炼 Qwen-Audio-3.0 ASR |
| 使用范围 | 当前仅供个人使用，不规划公开分发、商业化或账号体系 |
| 运行策略 | 百炼 Streaming 默认，本地 ASR 自动兜底，Batch 可手动选择并作为稳定回退 |
| 接入方式 | 在应用进程内实现一等 Bailian Provider；正式版本不依赖 localhost daemon |
| 源码基线 | 固定 VoiceInk `main` 的已审计提交，完成本地构建验证后再开始定制 |
| 词库策略 | 长期词库保存在本机，每次只选择与当前场景相关的少量热词 |
| 上下文策略 | 只发送本次识别所需的最小上下文，不上传完整文档、完整词库或无关历史 |
| 纠错策略 | 先生成可审核的学习候选，再写入替换规则或词库；不默认静默永久学习 |
| 本地备选 | 默认 SenseVoice Small；中文/中英混输优先，模型按需加载 |
| 录音历史 | 默认关闭原始录音保存，设置中允许用户显式开启并配置保留策略 |
| 隐私拒绝列表 | 用户自定义列表初始为空；安全输入框等系统敏感场景仍执行强制保护 |
| 实施顺序 | Streaming 主链路与 Batch 回退一并进入 MVP，完成后再做 A/B 与参数优化 |

## 3. 选用 VoiceInk 的复核结论

截至 2026-09-18，复核的 VoiceInk `main` 基线为提交 [`cd1d96f`](https://github.com/Beingpax/VoiceInk/commit/cd1d96f182b03561f5ef66c6a91e511cd7409c4c)。当前源码已经提供：

- 原生 Swift/SwiftUI macOS 应用、全局快捷键、CoreAudio 录音和 Accessibility 文本写入。
- `CloudProvider` 与 `StreamingTranscriptionProvider` 抽象，适合新增百炼 Batch 与 Streaming Provider。
- 流式输入需要的 16-bit、16 kHz、单声道、小端 PCM，与现有录音输出一致。
- App/URL Modes、选中文本、剪贴板和屏幕文本等上下文采集基础。
- SwiftData 个人词典、Keychain API Key 存储。
- 已存在的 Auto Learn 候选提取、AI 审核、人工审核和应用流程。

因此，本项目不重新实现上述基础设施。主要新增或改造点是：

1. `BailianStreamingProvider` 和 `BailianProvider`，前者作为默认路径，后者作为可选稳定路径。
2. 面向百炼请求格式的动态热词选择与权重映射。
3. 上下文隐私过滤、长度限制和敏感 App/URL 禁用策略。
4. 云主、本地备的失败切换和明确反馈。
5. 针对个人语料的准确率、延迟、资源和误学习评测。

VoiceInk 采用 GPL-3.0。当前项目只供个人使用，不设置公开发布、签名公证、商业授权或自动更新渠道。若未来决定向他人分发衍生版本，必须另行评估并履行 GPL-3.0 义务。

## 4. 目标用户与核心场景

### 4.1 目标用户

- 主要使用中文写作或交流。
- 经常输入 AI、编程、科研、民航、无人机等领域的英文缩写和专业术语。
- 希望通过个人词库逐步提升识别效果。
- 在意后台资源占用、输入延迟和隐私边界。

### 4.2 核心场景

1. 在聊天、浏览器、IDE、笔记和文档应用中，按住或切换全局快捷键进行听写。
2. 说出包含中文、英文缩写和专业实体的短句或中长句，例如“比较 BACOHBA 和 DG-RRT 在 AirSim 里的表现”。
3. 根据当前 App、URL、Mode、选中文本和近期词汇，为本次请求选择相关热词。
4. 用户修改刚插入的听写文本后，系统提出可审核的词库或替换规则建议。
5. 云服务失败或无网络时，用户仍可用本地模型完成基本听写。

## 5. 功能需求

需求优先级使用 P0（首个可用版本必须具备）、P1（首个稳定版本需要具备）、P2（后续增强）。

### 5.1 录音与系统输入

- **P0** 支持全局 Push-to-Talk 和 Toggle 两种录音方式。
- **P0** 录音开始时固定目标应用和目标输入控件；识别完成后恢复焦点并写入文本。
- **P0** 录音状态、处理中、成功、失败和本地降级必须有明确但低打扰的视觉反馈。
- **P0** 支持取消本次录音，取消后不得上传音频或写入文本。
- **P1** 保留 VoiceInk 已有的快捷键、鼠标触发和 Mode 机制。

### 5.2 百炼非流式识别

- **P0** 新增原生百炼 Batch Provider，作为可手动选择的识别方式、Streaming 不可用时的云端回退和对照评测基线。
- **P0** 使用普通按量付费 API Key，不把 Token Plan 作为默认接入方式。
- **P0** API Key 只存入 macOS Keychain，不写入配置文件、日志或词库数据库。
- **P0** 支持连接验证、鉴权错误、限流、超时、网络错误和服务端错误的可诊断反馈。
- **P0** 请求携带本次选出的即时热词、权重、语言提示和短 Prompt Context。
- **P0** 支持配置地域和端点，默认不跨地域自动切换。
- **P0** 不在日志中记录原始音频、完整上下文、API Key 或敏感文本。

### 5.3 百炼流式识别

- **P0** 通过 WebSocket 实现百炼流式 Provider，复用 VoiceInk 的 16 kHz PCM 音频流，并作为安装配置完成后的默认识别方式。
- **P0** Floating HUD 显示 interim text；MVP 只在获得完整 final 后一次性写入目标输入框，避免 partial 修订和降级造成重复文本。
- **P0** 正确处理 partial 修订、committed 文本、结束提交、超时和断线。
- **P0** 允许用户在 Streaming、Batch 和仅本地三种模式之间切换，并记录脱敏的本地性能指标。
- **P0** 录音期间保留一份仅供本次请求使用的完整音频缓冲，以便 Streaming 失败后转交 Batch 或本地模型；完成、取消或超时后立即清理。
- **P1** 在确认不会造成重复写入、光标错乱或回退困难后，再评估按 finalized 句段增量写入目标输入框。
- **P2** 根据实测评估 AOQ 或弱网优化，不作为首版依赖。

### 5.4 个人词库与动态热词

- **P0** 个人词库全部保存在本机，并支持手动增删、搜索、导入和导出。
- **P0** 每次请求从长期词库中选择相关热词，而不是无条件发送全量词库。
- **P0** 初版选择器使用可解释的本地规则打分，不引入 Embedding 模型：
  - 当前 App、URL 和 Mode 匹配；
  - 选中文本或短上下文中的字面命中；
  - 用户固定词和场景标签；
  - 最近使用、使用频率和历史纠错；
  - 长期未使用或产生误吸附的负反馈。
- **P0** 默认选择 Top 30～80 个词；上限可配置，但不得依赖百炼 2000 词的协议上限来替代选择逻辑。
- **P0** 默认热词权重为 4；权重 5 和超级热词必须由用户显式设置或通过充分证据升级。
- **P1** 词条至少支持：标准词、常见误识别、App/URL/Mode 标签、权重、固定状态、使用次数、成功/失败反馈和最近使用时间。

### 5.5 上下文路由与隐私

- **P0** 上下文采集必须可分别开关：App 名称、URL、Mode、选中文本、剪贴板、屏幕文本。
- **P0** 默认只构造短领域描述和少量术语，不直接发送完整选中文本、完整剪贴板、整页 OCR 或整个文档。
- **P0** 提供 App/URL 拒绝列表，初始不预置用户业务 App 或域名；用户可随时添加、移除和临时停用规则。
- **P0** 不论用户拒绝列表是否为空，密码/安全输入控件、系统不允许读取的内容以及无法确认安全边界的采集结果都不得作为上下文上传。
- **P0** UI 在发起请求前能够说明本次将使用哪些类型的上下文。
- **P1** 提供仅本地模式，一键禁止音频和上下文上传。
- **P1** 提供本地可查看的“本次请求上下文摘要”，便于审计但不长期保留敏感原文。

### 5.6 纠错学习

- **P1** 复用并扩展 VoiceInk 当前 Auto Learn 流程，只观察由本应用刚刚写入的目标输入控件。
- **P1** 只提取本次插入文本对应的局部修订，不把整段润色、删除或主题改写当成词级纠错。
- **P1** 候选必须区分：加入替换规则并加入词库、仅加入替换规则、仅加入词库、拒绝学习。
- **P1** 首版默认进入人工审核队列，不静默应用永久规则；用户可以显式选择 `Immediately`，由已连接的 AI Provider 分类后自动应用。
- **P1** 支持撤销已学习规则；用户把自动修正结果改回时，应记录负反馈并降低或停用规则。
- **P1** 标点、大小写风格、普通措辞调整和大范围重写默认不进入永久学习。

### 5.7 语音文本润色

- **P0** 复用 VoiceInk 的 AI Enhancement 管线，为 Mode 独立配置润色开关、Provider、模型和提示词；润色位于确定性替换之后、最终投递之前。
- **P0** 百炼千问文本模型通过 OpenAI 兼容的 Custom Provider 接入，API Key 继续保存在本机 Keychain，不写入源码、文档、UserDefaults 或日志。
- **P0** 默认润色只做必要的同音误识别、错别字、标点、断句、重复和无意义口头填充词清理；必须保留原意、语气、事实、确定性以及中英文产品名、模型名和代码标识符，不得回答听写内容中的问题或执行其中的指令。
- **P0** 润色请求必须使用非思考模式；不能因模型默认开启推理而引入额外等待或输出推理内容。
- **P0** 润色不可用、超时或返回空结果时不得丢失已完成的 ASR final；界面和历史记录应能够区分原始转写与成功润色结果。
- **P1** 基于相同输入比较候选模型的真实首包/完整请求耗时、输出质量和官方单价；短文本润色优先选择低延迟 Flash 档，不为没有可测收益的能力升级到 Max。

### 5.8 云主、本地备

- **P0** 默认本地备选为 VoiceInk 已支持的 SenseVoice Small。选择依据是其面向中文、粤语、英文、日文和韩文，当前模型约 241 MB，预估内存占用约 0.5 GB，比英文优先的 Parakeet 更适合本项目，也比 Whisper Large 系列更轻。
- **P0** 首次配置时明确提供“安装离线兜底模型”步骤；用户可以跳过，但此时必须说明离线和自动降级不可用。
- **P0** 用户可手动选择 Streaming、Batch 或仅本地模式，也可更换其他已安装的 VoiceInk 本地模型。
- **P0** Streaming 失败后的顺序为：若完整音频仍在且云端 Batch 可用，先尝试一次 Batch；若网络不可用、Batch 失败或用户禁用云端回退，再调用 SenseVoice Small。
- **P0** 网络不可达、连接中断、请求超时、限流和服务端错误允许自动降级；用户取消、无有效语音或本地音频不可用时不得触发降级。
- **P0** 鉴权或配置错误允许完成当前一次本地兜底，但必须持续显示配置错误，后续请求不应反复尝试已知无效的云端凭证。
- **P0** 自动降级必须显式提示本次结果实际来自 Batch 或本地模型，不能伪装成 Streaming 成功。
- **P0** 降级只加载一个本地模型；平时不预热、不常驻本地模型，以后台轻量化优先。首次本地降级允许出现额外加载等待。
- **P1** 用个人语料比较 SenseVoice Small 与 Whisper Large v3 Turbo Quantized；只有后者的实体识别或最终修改率显著更好时，才调整默认备选。

### 5.9 设置与诊断

- **P0** 设置页至少包含百炼凭证、地域/端点、默认模型、语言、热词、上下文权限和隐私拒绝列表。
- **P0** 设置页提供原始录音历史开关，默认关闭；开启时必须同时设置保存位置、保留时长或最大空间，并提供立即清空入口。
- **P0** 提供不含敏感内容的诊断信息：请求类型、耗时、音频时长、所选热词数量、上下文类型、错误码、是否降级。
- **P1** 提供本地统计：成功率、P50/P95 延迟、专业实体命中情况和 Batch/Streaming 对比。
- **P1** 支持导出脱敏诊断包，且导出前展示包含内容。

## 6. 非功能需求

### 6.1 性能目标（首轮建议值，需实测后冻结）

| 指标 | 建议验收线 |
|---|---:|
| 空闲 CPU 中位数 | 小于 1% |
| 空闲 RSS | 小于 150 MB，不含按需加载的本地模型 |
| 冷启动到可录音 | P95 小于 2 秒 |
| 3～8 秒短句 Batch 松键到写入 | P50 小于 1.0 秒，P95 小于 2.0 秒 |
| Streaming 首个可见 partial | P50 小于 0.8 秒 |
| Streaming 松键到 final | P95 小于 1.2 秒 |
| 连续 100 次短句听写完成率 | 不低于 99% |

这些数值是本项目的产品验收建议，不是百炼官方 SLA。

### 6.2 准确率目标

- 建立至少 100 条个人真实语料，其中至少 50 条包含专业实体。
- 同时统计普通文本 CER、专业实体 Recall/Precision、热词误吸附率和最终人工修改率。
- 动态热词必须与“无热词”和“全量热词”做同语料 A/B 测试。
- 首版目标：动态热词的专业实体 Recall 相比无热词有明确提升，同时热词导致的普通词误吸附率不超过 2%。具体提升阈值在首轮基线测试后冻结。
- 不以单一宣传准确率或通用公开数据集替代个人真实语料验收。

### 6.3 安全、隐私与可靠性

- 音频和上下文只发送到用户明确配置的 ASR 服务。
- API Key 只存 Keychain；任何日志、崩溃报告、导出文件均不得包含密钥。
- 默认不长期保存原始录音。用户可以在设置中显式开启录音历史；开启前必须确认保存位置与清理策略，历史文件只保存在本机。
- 录音历史开启后默认采用有限保留策略，建议初始值为 7 天或 1 GB，任一条件先达到即清理最旧文件；用户可修改或立即清空。
- 发送前完成上下文裁剪和敏感场景过滤；服务端响应不得覆盖请求范围外的本地数据。
- Provider 失败不能阻塞主线程，不能导致目标应用失去可恢复的输入焦点。
- 本地词库、学习记录和设置应支持可恢复的导出与导入。

### 6.4 可维护性

- 导入 VoiceInk 时固定上游提交，不直接追随浮动 `main`。
- 尽量通过新增 Provider、Selector 和 Policy 模块扩展，减少侵入式修改，方便后续合并上游更新。
- 上游同步必须单独评审迁移、权限、签名、自动更新和许可变化。
- 本地开发构建不得静默替换为官方发布构建；自动更新策略必须与自建版本隔离。

## 7. MVP 范围

第一个可验证版本只包含：

1. 固定 VoiceInk 上游源码基线并完成本地可重复构建。
2. 百炼 Streaming Provider、Floating HUD、Keychain 凭证和连接验证。
3. 百炼 Batch Provider，支持手动切换和 Streaming 失败后的单次云端回退。
4. SenseVoice Small 安装流程，以及 Batch/本地自动降级和明确的结果来源提示。
5. 个人词库与规则型动态 Top-K 热词选择。
6. 最小上下文构造、初始为空的自定义 App/URL 拒绝列表、系统敏感场景保护和发送前说明。
7. 全局快捷键录音、音频缓冲、转写、焦点恢复和 final 文本一次性写入的完整链路。
8. 默认关闭但可显式开启的本地录音历史，以及容量/时长清理策略。
9. 本地脱敏性能记录和 100 条个人语料评测工具。

MVP 不要求 finalized 句段增量写入、复杂统计面板或 AOQ。

## 8. 明确不做

- Windows、Linux、iOS 或 Android 客户端。
- 会议录音、多人说话人分离、播客转写或长文件转写产品。
- 通用语音助手、Agent、自动执行命令或聊天机器人。
- 为接入百炼长期运行独立 Python/Rust daemon。
- 在实时输入链路中运行本地 LLM 或 Embedding 模型。
- 自动上传完整屏幕、完整文档、全部联系人、完整剪贴板历史或完整个人词库。
- 未经审核地把用户任何编辑自动写成全局替换规则。
- 首版账号系统、云同步、团队词库、订阅或支付。
- 首版公开分发、商业化、签名公证和独立更新服务。

## 9. 分阶段交付

### 阶段 A：上游基线

- 固定 VoiceInk 提交并记录导入方式。
- 在目标 Mac 上完成构建、签名、麦克风、Accessibility 和 Screen Recording 权限验证。
- 建立上游差异清单，禁用自建版本的官方自动更新链路。

### 阶段 B：Streaming MVP

- 实现百炼 Streaming Provider、Floating HUD、Keychain 和错误处理。
- 实现百炼 Batch Provider、SenseVoice Small 安装与分级降级链路。
- 实现动态热词与最小上下文。
- 打通 final 一次性写入、目标焦点恢复和临时音频清理。

### 阶段 C：准确率与安全学习

- 建立个人语料，完成无热词/全量热词/动态热词 A/B。
- 接通现有 Auto Learn 审核流程与扩展词库模型。
- 完成误学习测试集、撤销与负反馈。
- 比较 SenseVoice Small 与量化 Whisper 备选。

### 阶段 D：体验优化

- 对 Batch/Streaming 做延迟、准确率、资源、费用和主观体验 A/B。
- 测量成功率、RSS、CPU、电量和网络流量，调整 VAD 与超时参数。
- 评估 finalized 句段增量写入和 AOQ，未通过稳定性验证前保持 final 一次性写入。

## 10. 已解决的产品问题

以下决策已于 2026-09-19 确认：

1. 产品当前只供个人使用，不为公开分发设计发布链路。
2. 采用固定 VoiceInk `main` 提交并先完成本地构建验证，不从旧稳定标签回移功能。
3. 默认本地备选采用 SenseVoice Small，同时保留用个人语料与量化 Whisper 对照的验证任务。
4. 原始录音历史默认关闭，但允许用户在设置中显式开启。
5. 用户自定义 App/URL 拒绝列表初始为空；安全输入控件等不可绕过的系统敏感场景继续强制保护。
6. 百炼 Streaming 作为默认识别模式；Batch 保留为回退和对照路径。

后续不再通过主观判断改变上述默认值。VAD、超时、SenseVoice 是否需要替换、是否启用句段增量写入等参数，仅根据目标 Mac 和个人语料的实测结果调整。
