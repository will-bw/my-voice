# B3 动态热词与最小上下文

更新日期：2026-09-19

## 会话快照

每次百炼录音开始时，`RecognitionHintSnapshotBuilder` 只生成一次不可变快照。快照包含：

- 去重后的热词与协议权重；
- 最多 4 个语言提示；
- 不超过 400 字符的最小字面上下文；
- 上下文来源类型、隐私决策和候选/发送/抑制数量。

Streaming 在连接前接收该快照；若流式失败，Batch 回退沿用同一对象，不重新读取词库或上下文。日志只记录 A/B 路径、数量和来源类型，不记录热词明文或上下文正文。

在网络请求建立前，录音 HUD 显示一条临时审计摘要，只说明上下文来源类型和热词数量；收到 partial 后改为显示实时文本。摘要随录音上下文清理，不含原词、上下文正文或热词列表。

## 动态选择

完整 `VocabularyWord` 词库保留在本机且不连接 CloudKit。`AdaptiveTermMetadata` 作为独立侧表，以唯一的规范化词条关联，不修改上游词库模型。启动迁移会为缺失词条创建默认元数据；它不会合并或删除重复的可见词库条目，也不会自动添加标签、反馈或高权重。持久迁移失败时应用改用不写回原 store 的临时内存容器并显示存储警告，不会删除或重建原 store。

动态路径按以下可解释信号排序：固定词、上下文字面命中、App、URL、Mode、审核纠错、最近使用、使用频率、正反馈与负反馈。只给最近加入的少量全局词一个低分兜底，候选不足时不会补足到 30。

- 动态 Top-K 默认 50，可接受范围 30～80；
- 默认协议权重为 4；
- 权重 5 只来自用户设置或稳定正反馈；
- 权重 50 只读取用户显式设置；
- 多次负反馈可将词条排除，停用词不会进入动态路径。

词库词条右侧提供 `Auto`、1～5 和显式 `50` 权重菜单；非法权重会在模型层收敛为空，不会进入协议。App、URL host 和 Mode 是默认开启但可分别关闭的纯本地排序信号，不作为请求字段上传。一次成功识别只有在 Provider 原始文本确实命中已选词时，才增加该词的使用次数并在本地关联本次 App、URL 与 Mode，避免把后处理替换误当成 ASR 命中。

## 上下文隐私

内容读取前先检查：

1. Accessibility 是否能确认当前焦点边界；
2. 当前控件是否为安全输入控件；
3. App bundle ID 是否命中用户拒绝列表；
4. URL host 或其父域是否命中用户拒绝列表；
5. 当前 Mode 是否开启对应的选中文本、剪贴板或屏幕文本来源。

任何安全控件或无法确认的焦点边界都会阻止内容型上下文。自定义 App/URL 拒绝列表初始为空，可在百炼 Provider 的 “Recognition Hints & Privacy” 区域编辑、移除或整体暂停；暂停自定义规则不会关闭安全控件和未知边界的强制保护。

允许的原始文本只在内存中用于提取短小、去重的原词片段，构造完成后不写入 SwiftData、UserDefaults 或日志。不会上传完整文档、完整剪贴板、整页 OCR、完整词库或历史转写。

## 可重复 A/B 路径

百炼 Provider 设置页提供三种确定性路径：

| 路径 | 行为 | 用途 |
|---|---|---|
| No hotwords | 发送空热词表 | 无热词基线 |
| Full dictionary | 规范化去重后按稳定顺序取协议允许的前 2000 个 | 仅受控评测 |
| Dynamic Top-K | 规则评分并发送最多 30～80 个，默认 50 | 默认产品路径 |

三种路径只改变热词选择；同一条录音的 Streaming 与 Batch 仍共享相同快照。正式 A/B 必须固定同一批音频、模型、地域、语言和上下文配置，并记录 CER、专业实体 Recall/Precision、误吸附率、修改率与延迟。

## 验证

```bash
xcodebuild test \
  -project VoiceInk.xcodeproj \
  -scheme VoiceInk \
  -configuration Debug \
  -destination 'platform=macOS' \
  -skipPackagePluginValidation \
  -skipMacroValidation \
  -only-testing:VoiceInkTests
```

当前完整回归的 51 个 XCTest 包含 B3 专项覆盖：规则排序、去重、Top-K 不补齐、显式权重边界、负反馈、三个本地信号独立开关与使用回写、400 字符裁剪、安全控件、自定义拒绝列表暂停、HUD 脱敏摘要、旧词库 store 迁移，以及 Streaming/Batch 快照一致性。当前 Mac 的真实本地 store 也已完成原地迁移与重启验证。真实百炼准确率 A/B 仍需要用户的普通按量 API Key 和个人语料，不能用 Mock 结果替代。
