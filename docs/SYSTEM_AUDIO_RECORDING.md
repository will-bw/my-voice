# 系统声音与麦克风同时录制

修改日期：2026-10-26。

## 使用

1. 打开 my-voice 的“音频设置”，选择自己的麦克风。
2. 开启“同时录制系统声音”，点击“授权系统声音录制”。
3. 在 macOS“隐私与安全性 → 屏幕与系统音频录制”（部分系统版本显示为“屏幕录制”）允许 my-voice；如果系统要求重启应用，请按提示重启。
4. 保持耳机与腾讯会议的扬声器输出正常，使用原来的录音快捷键开始与结束录音。录音面板出现扬声器图标时，表示本次正在同时采集系统声音。

该开关默认关闭，并在下次录音时生效。开启后，软件不会自动静音系统或暂停媒体；原有静音、暂停偏好仍保留，用于关闭该模式后的普通录音。

系统声音来自其他应用的数字音频流，独立于麦克风是否能听到耳机声音。它会包含所有其他应用播放的声音。软件自身的提示音被排除。此模式不保存屏幕图像，也不提供发言人区分；现有可选的屏幕上下文功能仍由其自身设置控制。

## 实现

- 麦克风继续使用原有 AUHAL 输入设备选择、合盖回退和设备切换。
- 系统声音使用 macOS ScreenCaptureKit，只注册音频输出，支持项目现有 macOS 14.4 最低版本。
- 两路输入使用各自的 host-clock 时间戳，经 AVAudioConverter 转为 16 kHz 单声道，按同一时间轴混合。每路采用 0.5 增益为同时发言留出余量；超出 PCM 范围时限幅。
- 混音队列保留 350 ms 等待窗口，避免独立音频回调的到达顺序导致丢音；迟到的数据不移动到后续位置。缺失片段以静音补齐，不等待没有声音的音轨。
- 同一份 16-bit PCM 同时写入 WAV 并送往原有实时识别回调；停止时先排空两路采集队列，再写完剩余片段并关闭文件。
- 权限拒绝会中止启动；系统音频中断会提示并结束本次录音，将中断前内容交给原有转写流程。
- 混音文件仍遵循原有录音历史开关、临时文件清理和保留策略。选择云端服务意味着两路混合音频都会发送给该服务。

- 已更新 `/Applications/my-voice.app`，本次旧版保存在 `.local-build/my-voice-before-system-audio.app`，另有同版构建产物 `dist/my-voice.app`。
- 已在安装后的应用界面核对中文说明、开关切换及静音/暂停/恢复延迟的禁用状态。检查后恢复双路开关关闭，保留原有普通录音偏好。
- 初次检查时尚未识别到系统录制权限。随后用户反馈系统设置中的开关已开启，但录音反复要求授权；排查与修复结果见下节。真实腾讯会议通话尚未验收。

## 已开启权限却反复提示授权的修复记录

2026-10-26：录音日志中的 `MixedAudioError.permissionRequired` 来自软件的前置判断；系统日志同时记录旧代码签名要求匹配失败。改用 ScreenCaptureKit 直接检查后，实际接口仍返回 `SCStreamErrorDomain / -3801`，说明系统中的开启状态尚未对应到有效的当前应用授权。

处理结果：

- 录音启动直接调用 ScreenCaptureKit，由实际接口执行授权检查；不再用 Core Graphics 预检查拦截。设置页也改用同一 API 查询，避免成功结果被另一套检查覆盖。
- 已通过系统设置核对该条目实际对应 `/Applications/my-voice.app`。用户完成 macOS 触控 ID 验证后，移除旧授权条目，再将这个确切路径的当前应用重新加入原有“录屏与系统录音”列表。
- 重新启动后，应用实际查询成功，音频页面显示“系统声音录制权限：已授权”，双路录音保持开启。尚未进行真实通话录音验收。
- 修复后全部 87 项单元测试通过，其中权限成功、拒绝和重新查询的回归测试 3 项。Release 签名构建已更新到 `/Applications/my-voice.app`，旧版保存在 `.local-build/my-voice-before-permission-fix.app`。

以后如果系统开关开启而实际接口仍返回 `-3801`，应核对授权对应的应用路径和签名关联。需要重建条目时，先退出应用，在系统设置中移除旧条目，通过“添加”选择 `/Applications/my-voice.app`，完成系统要求的本人验证后重新启动。不要只根据设置页面的开关外观判断采集接口已获准。

## 腾讯会议实机验收

1. 戴耳机加入会议，选择正确的麦克风，开启双路录音；双方分别说不同的短句，再同时说话，结束后核对转写。需要回放核对时，先开启原有录音历史功能。
2. 自己不说话，让对方持续说话，确认系统声音单独存在时也能转写；再让对方静音，只检查自己。
3. 在录音过程中切换耳机输出，检查系统声音连续性；切换麦克风后确认所选设备与回退提示。
4. 关闭双路开关，再录音，确认恢复普通麦克风输入及原有静音偏好。
5. 拒绝或撤销录制权限，确认提示错误且不会继续显示双路录音成功。
